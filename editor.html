Rutesøk

Velg avreise- og ankomstflyplasser, datointervall, og søk direkte mot awardhacks.se. Lagre oppsettet ditt som config.json for daglige Telegram-varsler.

GitHub-tilkobling
Lagres kun i denne nettleseren. Bruk en fine-grained token begrenset til dette ene repoet, med kun "Contents: Read and write" -rettighet. Se README for hvordan du lager en. Uten dette kan du fortsatt bruke "Last ned config.json" manuelt.
Hver søkegruppe kan ha flere avreiseflyplasser og flere ankomstflyplasser samtidig - alle kombinasjoner sjekkes. Legg til flere grupper for f.eks. både ut- og hjemreise. La datofeltene stå tomme for å få treff på alle datoer.
